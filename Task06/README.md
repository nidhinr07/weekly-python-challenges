
# Airbnb Homepage Clone

A responsive Airbnb homepage clone built using HTML and CSS. This project recreates the main layout of a travel accommodation website, including navigation, search options, destination cards, featured properties, and a footer.

## Features

- Responsive navigation bar with Airbnb branding
- Stays, Experiences, and Online Experiences links
- Login and Sign Up buttons
- Search section with location, check-in, check-out, and guest options
- Hero section with a background image and call-to-action button
- Six popular destination cards with images and descriptions
- Eight featured property cards with ratings, locations, and nightly prices
- Footer with Support, Hosting, Airbnb, Privacy, and Terms links
- Social media icons
- Hover effects and responsive layouts for different screen sizes

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
- Unsplash Images

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/nidhinr07/airbnb-clone.git
   ```

2. Open the project folder:

   ```bash
   cd airbnb-clone
   ```

3. Open `index.html` in your browser.

   You can also use the Live Server extension in Visual Studio Code.
