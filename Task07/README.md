
# Zomato Homepage Clone

A responsive food discovery and restaurant listing homepage built using HTML5 and CSS3. This project recreates a modern food ordering interface with restaurant listings, food categories, promotional offers, and a responsive layout.

## Features

- Navigation bar with Zomato branding
- Restaurant search and location input
- Hero section with food background image
- Six food category cards with images and descriptions
- Eight popular restaurant cards
- Restaurant ratings, cuisines, average cost for two, and delivery times
- Three promotional offer cards with Order Now buttons
- Footer with company information, restaurant partners, customer support, and legal links
- Social media icons
- Hover effects and responsive layouts for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Font Awesome
- Unsplash Images

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/nidhinr07/zomato-clone.git
   ```

2. Navigate to the project folder:

   ```bash
   cd zomato-clone
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
